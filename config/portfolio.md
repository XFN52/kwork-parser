# Портфолио проектов разработчика (Шаблон)

База подтверждённых фактов о проектах, архитектурных решениях и технологических компетенциях для автоматического подбора релевантных кейсов и составления персонализированных откликов ИИ-ассистентом на бирже фриланса.

---

## Как это работает?
1. ИИ-ассистент анализирует ТЗ заказчика на бирже фриланса (Kwork, Profi.ru).
2. Сканирует этот файл и выбирает 1-2 наиболее релевантных проекта, в которых решались похожие задачи.
3. Упоминает реальные архитектурные детали (стек, библиотеки, вызовы, метрики) без общих фраз и выдумывания несуществующего опыта.

---

## Примеры проектов

### 1. Freelance Order Monitor & AI Proposal Assistant (Kwork & Profi.ru)
- **Стек**: Python 3.11+, Asyncio, HTTPX (AsyncClient), BeautifulSoup4, GraphQL Client, SQLite3, Telegram Bot API, OpenAI API (DeepSeek/Ollama), PyPDF, Docker Compose.
- **Назначение**: Асинхронный сервис круглосуточного мониторинга бирж фриланса, локальной дедупликации, чтения вложенных файлов ТЗ и генерации откликов через LLM в 3 ценовых режимах.
- **Архитектурные решения**:
  - Прямой сбор SSR HTML и GraphQL без тяжелых браузеров, низкое потребление памяти (<50 МБ RAM).
  - Реляционная дедупликация в SQLite с автоматической очисткой устаревших записей (TTL 30 дней).
  - Интерактивный Telegram-интерфейс с постоянным 9-кнопочным меню и авто-разбивкой сообщений длиннее 4096 символов.
  - Multi-stage Docker Compose контейнер с непривилегированным пользователем appuser.

### 2. High-Load REST API & Data Pipeline
- **Стек**: Python 3.12, FastAPI, Pydantic v2, PostgreSQL, SQLAlchemy (asyncpg), Redis, Alembic.
- **Назначение**: Микросервис обработки и валидации потоковых данных с кэшированием и ролевой моделью.
- **Архитектурные решения**:
  - Быстрая валидация сложных схем данных через Pydantic v2.
  - Кэширование тяжелых агрегационных отчетов в Redis со временем жизни (TTL) 15 минут.
  - Автоматическая документация OpenAPI / Swagger.

### 3. Интеграция с LLM и автоматизация документооборота
- **Стек**: Python, OpenAI API / Local LLM (Ollama), PyPDF, python-docx, Celery.
- **Назначение**: Извлечение сущностей, суммаризация и классификация пользовательских файлов в фоновом режиме.
- **Архитектурные решения**:
  - Потоковая обработка многостраничных документов с разбивкой на чанки.
  - Структурированный вывод (JSON mode / Tool calling) с валидацией схемы ответов.
